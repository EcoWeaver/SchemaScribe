SchemaScribe
============

`SchemaScribe <https://github.com/EcoWeaver/SchemaScribe>`__ is a modular, schema-driven pipeline for LLM-assisted annotation of scientific literature. 
It is a work in progress, developed as part of the university course *Software Development Project* (SWEP) in cooperation with the University of Waterloo, as part of the EcoWeaver project. 
Its documentation and features are still evolving and may change at any time.

About EcoWeaver
---------------

`EcoWeaver <https://github.com/EcoWeaver/>`__ is an initiative aiming to weave together ecological knowledge from diverse sources, 
using state-of-the-art computational technologies, and create an infrastructure that includes an openly accessible knowledge base that adheres to the FAIR and CARE principles 
and the tools to create, manage, and access it.
